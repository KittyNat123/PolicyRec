# 마이페이지 기능구현 내역

## 1. 데이터베이스 변경 사항
*   **테이블:** `user_info`
*   **컬럼:** `user_type` (VARCHAR) 추가
*   **설명:** 사용자 신분(청년, 창업 준비생 등) 구분 및 추천 가중치에 활용

## 2. RAG 기반 개인화 추천 로직 -> 기능 테스트는 못했습니다. 주말중에 수정하겠습니다
사용자의 정적/동적 데이터를 컨텍스트(Context)로 활용하는 하이브리드 추천 방식입니다.

### 핵심 프로세스 (RAG 워크플로우)
1.  **컨텍스트 구성 (텍스트화):**
    *   **정적 정보:** 내 정보(나이, 지역, 분야, 유형)
    *   **동적 정보:** 최근 스크랩한 공고 제목 및 **챗봇 검색 이력**
    *   위 데이터를 결합해 "이 사용자의 관심사와 프로필에 가장 적합한 정책은?" 이라는 **가상 질의문(Virtual Query)** 생성
2.  **벡터 임베딩 (Vector Embedding):**
    *   생성된 가상 질의문을 **Gemini API**를 통해 고차원 벡터로 변환
3.  **시맨틱 검색 (Semantic Search):**
    *   변환된 벡터를 DB 내 공고 데이터 벡터와 비교해 **유사도(Cosine Similarity)**가 높은 항목 추출
    *   `match_announcements_hybrid` RPC를 사용하여 키워드 필터링과 벡터 검색을 동시 수행
4.  **후처리 (Post-Processing):**
    *   이미 스크랩한 공고는 결과에서 제외하여 추천의 신선도 유지

### 추천 우선순위
*   **1순위:** 스크랩 및 챗봇 이력 기반 (사용자가 직접 관심을 보인 공고와 유사한 정책)
*   **2순위:** 내 정보 기반 (사용자 프로필 조건에 부합하는 정책)

## 3. 향후 계획 및 데이터 활용
*   **챗봇 대화 로그 활용:** 챗봇 대화 데이터가 축적됨에 따라 사용자의 질문 문맥을 분석하여, 관심 키워드를 자동으로 추출하고 이를 추천 가중치에 추가 반영할 예정입니다.
*   **추천 정교화:** 스크랩 이력과 대화 로그를 결합하여 사용자의 실시간 관심 변화에 대응하는 동적 추천(Dynamic Recommendation) 시스템으로 고도화할 계획입니다.
