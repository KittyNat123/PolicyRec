# PolicyRec E2E Checklist

## 1. 환경 확인

- [v] `web/.env.local` 파일이 존재하는지 확인한다.
- [v] `SUPABASE_URL` 키가 있는지 확인한다.
- [v] `SUPABASE_SERVICE_KEY` 키가 있는지 확인한다.
- [v] `GEMINI_API_KEY` 키가 있는지 확인한다.
- [v] `AUTH_SECRET` 키가 있는지 확인한다.
- [v] 환경변수 값 자체는 화면/문서/채팅에 노출하지 않는다.

## 2. 빌드 검증

`C:\Users\min2m\github\PolicyRec\web`에서 실행한다.

```powershell
npm.cmd run lint
npm.cmd run build
```

- [v] lint가 통과한다.
- [✅] build가 통과한다.
- [ ] 실패 시 원인을 코드, DB, 권한/환경변수, 데이터 중 하나로 분류한다.

## 3. 검색/필터

- [v] 검색어로 정책 검색이 된다.
- [v] 카테고리 필터가 적용된다.
- [v] 지역 필터가 적용된다.
- [v] 나이 필터가 적용된다.
- [v] 모집상태 필터가 적용된다.
- [v] `모집완료까지 보기`가 동작한다.
- [v] `검색 초기화`가 동작한다.

## 4. 회원/세션

- [v] 회원가입이 된다.
- [v] 로그인이 된다.
- [v] 새로고침 후 로그인 상태가 유지된다.
- [v] 로그아웃이 된다.
- [v] 로그아웃 후 스크랩/필터 저장 기능이 제한된다.

## 5. 스크랩

- [v] 로그인 후 정책 2~3개를 스크랩한다.
- [v] 새로고침 후 스크랩 개수가 유지된다.
- [v] `스크랩만 보기` 클릭 시 현재 검색 결과와 무관하게 전체 스크랩 공고가 보인다.
- [✅] 스크랩만 보기 상태에서 스크랩 해제 시 목록에서 바로 제거된다.
- [v] 로그아웃 시 스크랩 모드가 해제된다.
- [✅] `/scraps`에서 전체 스크랩 목록이 보인다.

## 6. 프로필

- [✅] `/profile`에서 로그인 ID가 보인다.
- [v] 저장 필터의 지역/카테고리가 보인다.
- [✅] 스크랩 개수가 실제 스크랩 수와 맞는다.
- [v] 최근 스크랩 카드에서 스크랩 해제 시 목록이 갱신된다.
- [✅] 비로그인 상태에서 `/profile`, `/scraps` 접근 시 로그인 안내가 보인다.

## 7. 챗봇

- [v] 챗봇 FAB가 열린다.
- [v] 자연어 질문 후 정책 카드가 표시된다.
- [v] 답변 문구가 검색 결과의 제목/지역/마감일/요약 범위 안에서 생성된다.
- [x 유지안됨. 이건 나중에 저장하고 싶으면 저장버튼 누르고 채팅방처럼 보여주기로했어.] 새로고침 후 대화 기록이 유지된다.
- [x 저장이 안되니 기록삭제도 없어.] `기록 삭제` 클릭 후 새로고침해도 기록이 비어 있다.
- [v 이건 저장이 안돼서 분리되는거같아. 로그인/비로그인보다는 ] 로그인 사용자와 비로그인 상태의 대화 기록이 분리된다.

## 8. 상세 링크 없음 보완

- [v] `detail_url`이 있는 카드는 제목 링크가 새 탭으로 열린다.
- [v] `detail_url`이 없는 카드는 제목 링크 없이 표시된다.
- [?] `detail_url`이 없는 카드에 `상세 링크 없음` 배지가 보인다.
- [? : 요약, 제공기관, 대상, 대상태그 4가지 보임] 카드 `자세히 보기` 확장 시 신청방법/제출서류/추가조건 등 가능한 상세 정보가 보인다.
- [? 이게뭔소리인지? 구글,네이버 공고명으로 검색은 없앴어. 그리고 url 연결했는데 공식홈페이지 첫화면으로 떠서 그것도 수정이 필요할 거 같아] `공고명으로 검색` 버튼이 과도하게 공식 링크처럼 보이지 않는다.
